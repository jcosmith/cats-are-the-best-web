# Cats Are the Best

A 20-slide, science-backed web presentation on cats, mostly about **how to train your cat**: clicker training, targeting, recall, tricks, scratching, litter boxes, carrier training, cooperative care, harness walking and enrichment.

**View it live:** https://jcosmith.github.io/cats-are-the-best-web/

## Files

| Path | What it is |
|------|------------|
| `cats-are-the-best.html` | The presentation, a single self-contained HTML file |
| `index.html` | Redirects to the presentation (for GitHub Pages) |
| `resources.md` | The plan, slide outline, all sources, and image credits |
| `images/` | Photos used in the slides |

## Navigation

Use the arrow keys, Page Up/Down, Space, Home/End, the on-screen buttons, or swipe on touch screens. Add `#n` to the URL to jump to slide *n*. The ◐ button toggles light and dark themes.

## Credits

The training advice and statistics come from peer-reviewed studies, veterinary bodies (AAFP/ISFM, International Cat Care) and humane societies. The full list is in [`resources.md`](resources.md).

All photos come from [Wikimedia Commons](https://commons.wikimedia.org/) under CC0, CC BY, CC BY-SA or public-domain terms. They were resized and are otherwise unchanged. Each slide's caption credits the author and links to the license, and [`resources.md` §4](resources.md#4-image-credits) has the complete table.
